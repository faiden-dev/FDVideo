# FDVideo

FDVideo is a desktop-oriented video editor for creating, editing and managing video projects with a simple and modern interface.

## Built with

- React
- TypeScript
- Vite
- Node.js
- HTML
- CSS

## Project structure

- `src` - application source code
- `server` - local Node.js server
- `docs` - project documentation
- `index.html` - main HTML entry point

## Commands

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Start the local server:

```bash
npx tsx server/index.ts
```

Build:

```bash
npm run build
```
