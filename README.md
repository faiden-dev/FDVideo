# FDVideo

FDVideo is a desktop-oriented video editor for creating, editing and managing video projects with a simple and modern interface.

## Built with

- React
- TypeScript
- Vite
- HTML
- CSS

## Project structure

- `src` - application source code
- `src/pages` - application pages
- `index.html` - main HTML entry point

## Commands

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```
