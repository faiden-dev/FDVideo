# Home Page



## src/pages/home.tsx

The application start page.

- Header at the top with the application title and settings button. Project grid is displayed in the center.
- Settings open a small overlay window with options for theme, language, project storage folder and other application settings.
- Project tiles display the project name and project settings. Clicking a tile opens the editor page for that project.

Example:

```text
            FDVideo         *
┌────────────┐  ┌────────────┐
│ Project 1  │  │ Project 2  │
└────────────┘  └────────────┘
┌────────────┐  ┌────────────┐
│ Project 3  │  │ Project 4  │
└────────────┘  └────────────┘
```
